# 中文自然度与去 AI 味审查（剧本版）

综合来源：[Humanizer-zh](https://github.com/op7418/Humanizer-zh) 的 24 类中文问题分类、[ai-to-human-zh](https://github.com/Holden323/ai-to-human-zh)（14 年老编辑工具包）、[speak-human-tw](https://github.com/Raymondhou0917/speak-human-tw)（38 种 AI 写作痕迹，参考朱宥勳与维基百科社群观察），并统一改写为影视剧本场景适用。只借用"问题分类与改写思路"，不引入其检测器、评分或代码。

## 为什么会有 AI 味

模型按"下一个字最可能是什么"生成，内容必然往**最常见、最保险、最正向**靠拢（均值回归）。结果：用词笼统、什么都提一下、每段用一句漂亮总结收尾，却**没有一句是非它不可的具体细节**。

处理优先级：**先删 → 再具体化 → 再降格式**。删掉后补不出具体内容的句子，本来就不该存在。

## 两条前提（别误杀）

1. **AI 味的根源是平庸，不是错误。** "不是 A 而是 B"、排比、破折号本身都是正常写法；错的是它们**出现的密度**，以及**底下有没有东西撑着**。判断标准：有具体事实撑就放行，没有就砍。
2. **形式正确 ≠ 内容正确。** 清掉痕迹只处理形式，想法要作者自己有。别以为把清单清干净，这段戏就有内容了。

## 一、禁令句式（出现即改，改成直接陈述）

- **否定平行结构**：`不是…而是…`、`不是…是…`、`不仅是…更是…`、`你以为…其实…`。
  - 病：`他不是不想社交，而是不知道如何社交。`
  - 改：`他不敢约人。`（删掉"不是 X"半句，或整句重写；全文字面形式最多留 1 次，其余换"并排短句、情境对比、时间对比"等隐形式）
- **假第一人称**：`我见过太多…`、`我经历过…`、`我身边就有…`。AI 没有身体、没有经历，读者能闻到。直接说现象，删掉归属。
- **假坦白钩子**：`说真的`、`老实说`、`说穿了`、`跟你讲个秘密`——后面接的往往是一句很普通的话。删掉报备式停顿，让后面那句自己站。
- **替读者说蠢话再纠正**：`你可能会说…但实际上…`。别替观众说一句你方便反驳的话，直接说你想说的。

## 二、说教式深度腔与金句公式

- **说教式深度腔**：`说到底是`、`归根结底`、`本质上`、`真正的 X 是 Y`、`你以为是…其实是…`——假装拨开表象，实则把普通观点加个仪式感重讲一遍。
  - 病：`说到底，做内容真正的问题不在流量，而在你有没有想清楚为谁而写。`
  - 改：`我停更那三个月，是因为写的东西连我自己都不想看。`
- **金句公式**：`X 是 Y 的 Z`（"拖延是完美主义者的影子"）、`X 是新的 Y`（"注意力是新的货币"）——把平常主张铸成能印在马克杯上的句子。把格言还原成具体主张，还不出具体主张就删。连两句以上金句就是 AI 腔。

## 三、替换词表

### AI 高频词 → 删或换

| AI 味 | 替代 |
|---|---|
| 此外 / 事实上 / 值得注意的是 / 本质上 / 归根结底 | 删掉，直接说 |
| 然而 / 与此同时 | 但 / 不过 |
| 至关重要 | 很重要 |
| 彰显 / 体现 / 标志 | 删掉，换成具体事实（人数、日期、动作） |
| 格局 / 这意味着 | 删掉；"这意味着"要问"谁说的、根据什么" |

### 广告腔 / 乙方 PPT 词 → 删或换

| 禁用 | 替代 |
|---|---|
| 赋能 | 帮你 / 让你 |
| 痛点 | 你难受的地方 |
| 闭环 / 抓手 / 颗粒度 / 赛道 / 差异化 / 底层逻辑 | 删掉或换大白话 |
| 情绪价值 | 让人觉得舒服的东西 |
| 反常识的规律 | 直接说那个规律是什么 |

### 书面 → 口语（具体画面 > 抽象概念）

- 病：`他感到一种深层的孤独。` → 改：`他翻了一遍通讯录，没找到一个想联系的人。`
- 病：`好看的人有特权。` → 改：`他排了半小时队，那个好看的笑一下就过了。`
- 病：`你的身体在替你承受代价。` → 改：`你的身体在替你死扛。`
- 病：`他点了很多外卖。` → 改：`他上个月大晚上点了 17 顿外卖。`
- **写完问自己：观众脑子里能出现画面吗？不能就重写。**

## 四、标点即呼吸

- **破折号**：每 300-500 字最多 1 次，同段不连续出现两次；"揭晓"处多半用冒号或句号。台词里确有打断功能的不算。
- **段落拆分**：长段拆成 1-3 句一段；段落间空白就是呼吸。
- **句号 → 逗号**：后句是前句的延续（解释、转折、递进）用逗号连，全新意思才用句号断。
- **长短交替**：连续三句长度、结构几乎一样，就打乱——加一句两三个字的短句，或一句四十字不断的长句。
- **分号**：三个以上并列短句用分号连，别全用句号断开。

## 五、人工戏剧（剧本特有，重灾区）

- **罐头皮反应镜头**：`她愣了一下`、`我沉默了几秒`、`他看着屏幕没说话`——放在某句台词/信息后面，只负责提示"这里要感动/震惊"，没有新增事实。**没有不可替代的叙事或事实功能，就整句删**，不要换成"沉默了几秒"的同族另一句。有事件功能（交代时间、对话中断、关系变化、后续行动）才放行。
- **戏剧性短句轰炸**：连续三句以上极短句/残句排队砸下来，硬造史诗感。
  - 病：`然后，一切都变了。没有预兆。没有回头路。`
  - 改：`改版之后，后台数据整个变了——旧的爆款题目全部失灵。`
- **过度比喻**：一个意象反复展开、反复解释。比喻用一次就够。
- **过度加剧情**：故事已经说清楚了，再加个医生/旁白出来总结（"身体一直在给你发信号，你一次都没听"）。观众自己能懂。

## 六、结尾：刺穿，不是描述

- **弱结尾（描述行为）vs 强结尾（刺穿心理）**：
  - 弱：`他确认这个时间还有人醒着。`
  - 强：`手机屏幕亮着的时候，他还不是一个人。`
- **不要过度升华**：`趁还来得及，看清楚自己到底在写什么`——删掉，让戏自己结束。
- **金句密度**：每 600-800 字最多 1 个加粗金句，别每段都收得漂亮。
- **允许不收尾**：真人写到没话讲就停了。删掉罐尾后不必补新结尾——停在最后一个具体句子，或一个没答案的问题，都可以。

## 七、数据与引用

- **幻影引用 / 精确到不真实的数字**：`研究显示生产力提升 47.3%`（查无出处）、`他盯着屏幕看了 1.7 秒`（你量过吗？）。可疑引用标〔需查证来源〕；精确到小数点的时间/数字，换成"一会儿""几秒"。
- **模糊归因**：`有人认为`、`研究显示`（无出处）、`普遍看来`。改成第一手观察、具体出处，或删掉论断。
- **立场真空**：`各有优缺点`、`因人而异`、`见仁见智`——读完不知道作者站哪边。问"所以你选哪个、为什么"，写得出就换成判断句，写不出整句删。

## 八、24 类问题清单（全量）

### 一、内容模式

1. **意义/宏大趋势拔高**：小动作解释成时代、文明、命运的证明（标志、见证、里程碑、转折点）。
2. **名望与媒体背书堆积**：用"广受好评""业内公认"等空泛权威替代剧情证据。
3. **抽象分析替代具体行为**：用情绪标签代替人物做了什么、付出了什么。
4. **宣传/广告腔**：场景、人物、道具被写成"卓越、极具价值"的推介文案。
5. **模糊归因与无证据判断**：用"有人认为""普遍看来"掩盖信息来源。
6. **提纲式总结**：把场景写成"问题—挑战—展望"的报告，缺当下行动与反制。

### 二、语言与语法模式

7. **高频 AI 词汇堆积**：反复用空泛的"此外、至关重要、深入探讨、彰显、格局"。
8. **刻意回避普通系词**：用"呈现为、构成了、属于"替代自然的"是"，造成译文腔。
9. **否定式排比**：滥用"不是……而是……""不仅……还……"制造假转折。
10. **三段式过度对称**：连续把动作/形容词排成整齐三项（能用两个就不用三个；必须三个以上就用四个）。
11. **刻意同义词轮换**：为避重复强换人物本会重复的词。**重复不是错，换词才是。**
12. **虚假范围**：用"从……到……""无论……都……"等宽泛范围，却无场景证据支撑。

### 三、格式与装饰模式

13. **破折号过度**：把本可用停顿、句号、冒号处都写成破折号（台词中确有打断功能的不算）。
14. **粗体等强调标记泄漏**：把 Markdown 强调符号带进剧本正文。
15. **行内标题与竖向清单**：把一场戏拆成"重点：""关键是："等说明性小标题和列表。
16. **装饰性标题格式**：混用英文标题式大小写、全角装饰制造正式感（正常场号、场景标题不算）。
17. **表情符号/装饰符号**：非手机界面或世界规则需要，不用 emoji 当情绪快捷键。
18. **不必要的引号装饰**：引号只保留引用、特殊称谓与视听内容需要，不伪造语气。

### 四、交流与填充模式

19. **协作/助手元话语**：正文出现"下面我将""根据你的要求""本场重点是"等写作过程说明。
20. **知识截止/能力免责声明**：人物或场景冒出"截至目前资料""我无法确认"等模型式免责声明（除非确属人物对白）。
21. **谄媚与无依据肯定**：人物无动机地夸赞、认同或替观众确认"这个决定很正确"。
22. **填充短语**：删掉不改变行动/信息/关系的"值得注意的是""需要指出的是"。
23. **过度限定与保守措辞**：每句都用"可能、某种程度上"回避立场（真正不确定保留一层"可能"，确定的事零层）。
24. **通用积极结论**：每场用"这说明希望仍在""未来会更好"等抽象正能量收束，代替可见后果。

## 九、剧本专用检查顺序

1. 标出本场唯一不可缺少的**行动变化**与**价值变化**。
2. 扫禁令句式（不是…而是… / 我见过太多 / 说真的 / 说到底是）→ 改直接陈述。
3. 给每个命中的问题标注受损项：动作 / 信息 / 关系 / 节奏 / 人物声音。
4. 只删或改不影响行动的句子；不因去模板化删掉线索、专业术语、时代用语或类型承诺。
5. 对白按说话者的欲望、策略、知识边界、称谓、回避方式、会重复的词检查；不强求所有人长短句交替。
6. 重新朗读 + 连续性检查：人物没有得知未被提供的信息，改写没新增设定或因果。

## 十、风格校准（比"自然一点"更可执行）

用三列记录，放入 `style/screenplay-style.md`：

| 原句 | 命中的问题及证据 | 希望保留的效果 |
| --- | --- | --- |
| 她意识到自己失去了控制权。 | 3：直接命名心理，无可表演证据。 | 保留她开始失控的感觉。 |
| 她把钥匙插了两次，第二次没拧到底。 | 未命中；动作具体。 | 保留迟疑，不改成抽象心理。 |

用户自己的改写对照、被否决句、"为什么改、改后保留什么"都进这里。真实片段只学习句法、节奏、视角与人物差异，不复制其人物、情节或原句。

## 十一、60 秒快速自检

- [ ] 开头是"在当今……的时代"式帽子？删，从具体场景/动作/画面开始。
- [ ] 读完不知道作者站哪边（各有优缺点/因人而异）？补判断或删句。
- [ ] 连续三句长度、结构一样？打乱其中一句。
- [ ] 连续三句极短、硬砸戏剧感？并回正常句。
- [ ] 每段结尾都是漂亮总结句？换收法，或直接不收尾。
- [ ] 破折号超过每 300-500 字 1 次？改标点。
- [ ] "此外/然而/值得注意的是/说到底是/本质上/这意味着"出现？多半可删。
- [ ] 台词/旁白有"说真的/老实说/废话不多说"？删，直接讲。
- [ ] 有"她愣了一下/沉默了几秒"式罐头皮反应镜头？没有事实功能就删。
- [ ] 有硬铸的金句（X 是 Y 的 Z）？还原成具体主张。
- [ ] 清点"我见过/我经历过/我身边就有"？AI 没有身体，删。
- [ ] 抽掉主词这段还成立？塞回只有这段戏才有的细节。

## 边界

- 不作为"绕过 AI 检测器"的保证；可读性、人物差异、因果完整性优先。
- **警惕假人味**：去 AI 味时最容易误加"说真的/老实说/沉默了几秒/然后一切都变了"这类新的 AI 腔——它们恰恰是"装人味"的反效果。
- 不给所有人物统一加粗话、网络词、方言、错别字或断裂句。
- 不把正常中文的"是"、必要的破折号/引号/重复词一律判为问题。
- 不自动整场改写；潜台词、情感与高潮质量仍需结合人物与正文判断。
